Cómo añadir una actividad

Es muy sencillo — solo edita el array actividades en el archivo HTML.

01

Abre el HTML

Edita el archivo index.html con cualquier editor de texto (el Bloc de Notas también sirve).

02

Copia un bloque

Copia uno de los objetos del array y cambia el título, descripción, área y URL de tu actividad.

03

Pega la URL

Pega la URL de tu actividad HTML (de NogalesPT u otra web) en el campo url.

04

Sube a GitHub

Arrastra el archivo a tu repositorio de GitHub Pages y se publica automáticamente.
